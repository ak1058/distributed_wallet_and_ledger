# ADR-001: Transactional Outbox vs Direct Publishing

## Context
When processing a financial transfer, we update balances and need to emit an event to Kafka. Publishing directly inside the DB transaction can lead to inconsistencies if the DB commit fails after Kafka acknowledges the message.

## Decision
We implemented the Transactional Outbox Pattern.

## Trade-offs
- **Pros:** Guaranteed at-least-once delivery; DB and events are always consistent.
- **Cons:** Added latency for downstream consumers due to polling intervals.
